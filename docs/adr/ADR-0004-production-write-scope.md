# ADR-0004: 운영 DB 쓰기 범위 제한과 어드민 DB 분리

## 상태

Proposed — 2026-10-11

## 맥락

clever-lab-api는 삭제·금액·상태 변경 시 여러 문서를 함께 바꾼다 (명세서 삭제 시 의뢰서 연결 해제, 회계 합계 재계산, 거래처 누적 청구액 차감 등). 어드민이 운영 DB에 직접 쓰면 이 연쇄 처리가 빠진다. 상세 근거는 `docs/prd.md` 5장 "연쇄 처리".

## 결정

- 어드민은 운영 문서를 삭제하지 않는다. `infrastructure`에서 `deleteOne`, `deleteMany`, `findOneAndDelete`, `findByIdAndDelete`, `remove` 호출을 ESLint로 금지한다.
- 수정은 PRD가 허용한 필드만, 바뀐 필드만 `$set`으로 쓴다. 금액·상태·연결 필드는 도메인 엔티티에 변경 메서드를 두지 않는다.
- 감사 로그·접근 로그는 운영 DB가 아닌 어드민 전용 DB에 둔다.
- 운영 DB 계정 권한은 PRD 7장 범위로 제한한다.

## 결과

- 운영 데이터가 어드민 때문에 어긋나지 않는다.
- 삭제·금액 수정이 필요하면 2차에서 clever-lab-api 관리자 API로 처리해야 한다.
